Endpoints

GET /api/health
Saúde do banco
GET /api/incidents
Listar registros, paginação, filtro
GET /api/incidents/{id}
Buscar por ID
POST /api/incidents
Criar incidente (chave requerida)
PUT /api/incidents/{id}
Atualizar incidente (chave requerida)
PATCH /api/incidents/{id}
Atualizar parcialmente (chave requerida)
DELETE /api/incidents/{id}
Excluir incidente (chave requerida)
GET /api/stats
Estatísticas

Exemplo de JSON

{ "title": "Phishing simulado", "description": "Incidente fictício usado para teste de Cloud.", "severity": "low", "status": "open" }

Autenticação

Para operações POST, PUT, PATCH e DELETE, utilizar o cabeçalho x-api-key com valor fornecido exclusivamente no backend. Nunca inserir tokens ou chaves no frontend público ou GitHub.

Modelo SQL

Tabelas incidents, analyses, audit_logs, com chaves e relacionamento por incident_id. Banco persistente Turso, região AWS sa-east-1.
